# 06 — Storyboard et découpage technique

État : `[À FAIRE]` — commence après validation du scénario.

Organisation prévue, un dossier par scène :
```
S01/
├── S01_DECOUPAGE.md     Fiche de scène + liste des plans (gabarits dans ../_modeles/)
├── S01_P010.md          Fiche de plan
├── S01_P020.md
└── storyboard/          Vignettes (images) S01_P010_SB.png…
```

Chaque fiche de plan précise : cadre, valeur de plan, mouvement de caméra, axe (180°), durée visée, action, émotion, lumière, état de continuité d'entrée et de sortie, références à joindre, besoins de post (incrustations, son).
La durée visée des plans dépend des capacités de Fable 2 (Q-003).
