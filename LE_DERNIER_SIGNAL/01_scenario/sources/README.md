# 01_scenario/sources — Matériau scénaristique existant

Ce dossier contient, **tels quels**, les textes déjà élaborés par l'équipe : base scénaristique, notes, résumés, extraits de conversations.

- Un fichier par source.
- Ces textes ne sont **jamais réécrits** ici. Ils servent de source à l'inventaire (`../INVENTAIRE_SCENARISTIQUE.md`), puis à la bible et au scénario.
- Pour préserver l'intégrité d'une source, **rien n'est ajouté dans le fichier lui-même** : ses métadonnées sont tenues dans le registre ci-dessous.
- Une nouvelle version d'une source entre comme un **nouveau fichier** (`…_V02.md`). L'ancienne version n'est ni modifiée ni supprimée.

Pour vérifier plus tard que la source n'a pas changé : `sha256sum BASE_NARRATIVE_SIX_ACTES_V01.md`.
