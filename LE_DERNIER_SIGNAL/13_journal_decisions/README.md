# 13 — Journal des décisions (annexes)

Le journal principal est `../DECISIONS_LOG.md`. Ce dossier contient ce qui l'accompagne :

- `QUESTIONS_OUVERTES.md` — informations manquantes, ambiguïtés, incohérences à trancher.
- `annexes/` *(à créer au besoin)* — comparatifs d'options, captures de tests, comptes rendus de réunion, nommés `AAAA-MM-JJ_sujet.md`.
- `options_ecartees/` *(à créer au besoin)* — propositions refusées, conservées pour mémoire.
